# Semakan bank tetap — 8 November 2026

`EXPEDITION.bank` mempunyai 36 entri: tiga set dengan empat soalan bagi setiap peta. Semakan pembangun meliputi makna soalan, satu jawapan paling tepat, pilihan pengganggu, ilustrasi, audio dan kestabilan sesi. Ini bukan pengesahan kurikulum rasmi atau semakan guru pakar.

| Fokus | Variasi dan bentuk tugasan |
|---|---|
| Tembakau, alkohol, dadah terlarang | Tiga persembahan ilustrasi setiap kategori; label tersembunyi sebelum jawapan betul |
| Padanan gambar | Pasangan tembakau/alkohol, alkohol/dadah, tembakau/dadah dari kiri ke kanan |
| Bukti risiko / pilihan selamat | Dua kad setiap set dengan konteks berbeza; seret atau tekan kad dan kategori |
| Semak kenyataan | Kandungan bungkusan, arahan ubat, bentuk botol tidak menentukan isi |
| Penggunaan ubat | Ikut arahan doktor; tanya ahli farmasi tentang sukatan; jangan berkongsi ubat |
| Hud: beredar | Asap di laluan jeti, tempat menunggu bot atau tempat berehat |
| Izz: menolak | Pelawaan di pondok, hadiah minuman, cabaran supaya dianggap berani |
| Aini: bantuan | Bungkusan tanpa pemilik, rakan mahu membuka, adik menghampiri |
| Susun tindakan | Pelawaan mencuba bahan ketagihan: TIDAK → BEREDAR → BERITAHU |

Tiga variasi bagi enam fokus asal dikekalkan. Tiada prompt utama berulang dalam satu set; pengetahuan diperkukuh melalui tugasan berbeza. Set dipilih bergilir ketika sesi baharu bermula dan digunakan semula selepas tiga sesi.

Sebelas aktiviti pilihan diseimbangkan kepada A=4, B=4 dan C=3. Betul/salah hanya dua pilihan. Benih acakan disimpan. Ujian 40 benih bagi setiap set memastikan tiada tiga huruf jawapan sama berturut-turut dan makna jawapan betul kekal. Jawapan betul tidak sentiasa paling panjang. Kad susunan mengekalkan urutan jawapan yang dinilai; pemain memilih atau menyeret kad ke ruang jawapan.

Semua label A/B/C bagi setiap teks pilihan tersedia dalam katalog audio. Audio soalan menggunakan nombor stesen 1 hingga 4. Sesi lama mengekalkan susunan terdahulu supaya respons tersimpan tidak berubah; keseimbangan baharu terpakai kepada sesi baharu.

Pilihan pengganggu berkaitan dengan situasi: menutup hidung sambil kekal dalam asap, menyimpan hadiah alkohol, memeriksa bungkusan sendiri, meneka sukatan atau berkongsi ubat. Maklum balas menerangkan pilihan selamat tanpa memalukan murid. Tiada animasi mencuba bahan ketagihan.

Bungkusan Aini tidak dilabel sebagai dadah berdasarkan rupa. Pengenalpastian menggunakan kad pendidikan bertanda, bukan kaedah mengecam bahan sebenar. Ubat mengikut arahan doktor dibezakan daripada dadah terlarang.

Kod, dialog dan latihan tidak dikira sebagai respons pembelajaran. Bantuan dan jawapan salah tidak menyekat penamat. Semakan bahasa dengan guru dan ujian kefahaman murid belum dilakukan.
